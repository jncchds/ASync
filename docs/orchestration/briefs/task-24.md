## Scope
1. **`IContactsSource` over the Contacts framework** per the mapping notes: `CNContainer`s → accounts (identifier → id; local / Exchange / CardDAV → type label, iCloud being CardDAV, documented), `CNContact.identifier` → contact id, names, organisation, phones/emails/addresses/URLs/dates/IM/social/relations with their labels (system labels mapped, custom kept), notes (note: `CNContactNoteKey` needs the `com.apple.developer.contacts.notes` entitlement — leave notes out unsigned and document), `imageData` → PHOTO, `CNGroup`s → CATEGORIES. No per-contact version on iOS: decide between "every contact read and deduplicated" and `CNChangeHistoryFetchRequest` tokens (only if usable from .NET), document why. iOS 18 limited contacts access = `MediaAccess.Partial` (with `CNContactStore` limited access picker if reachable from .NET).
2. **`ICalendarSource` over EventKit:** `EKCalendar.calendarIdentifier` → id, `EKSource` → account, colour, events in the folder's window with `startDate`/`endDate`/`isAllDay`/`timeZone`, `recurrenceRules` → RRULE text, detached occurrences (EventKit lists occurrences: rebuild master + RECURRENCE-ID overrides correctly, keyed by `calendarItemExternalIdentifier`/UID), alarms, attendees (role/status/type, read-only on iOS), `lastModifiedDate` → LastModified so iOS events are incremental by time. Reminders (EKReminder) are out of scope unless trivial; say so.
3. **Permissions:** `NSContactsUsageDescription`, `NSCalendarsFullAccessUsageDescription` (iOS 17+ `requestFullAccessToEvents`) and the iOS 15/16 fallback, write-only vs full access explained, asked from the app's screens at the same moments as Android (read for backup, add only for restore where iOS distinguishes). Simulator permissions in CI: see task 23's TCC.db auth_version finding (services kTCCServiceAddressBook / kTCCServiceCalendar).
4. **Change triggers:** `CNContactStoreDidChange` and `EKEventStoreChanged` while running (debounced like task 23's `PhotoChangeDebouncer`, reuse it), plus the task 22 background plan includes Contacts/Calendars folders.
5. **Restore:** `CollectionRestorer` over `CNSaveRequest` (into the original container if it exists, else the chosen/default one; groups recreated) and `EKEventStore.save` (into the original calendar, else the chosen/default; recurrences and overrides, alarms; attendees cannot be written by EventKit — document), skipping what is there by UID as Android does; never deletes.
