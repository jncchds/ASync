Goal: a desktop app for Linux, Windows and macOS that people use instead of async-cli. Installers and auto-update are the next task (M3-3), not this one.

1. Projects: `src/ASync.App` (shared Avalonia UI, CommunityToolkit.Mvvm, views and view models that will also be used by the iOS/Android heads in M4, so keep them free of desktop-only APIs behind interfaces) and `src/ASync.App.Desktop` (the desktop head: tray icon, window, single instance, autostart). Use current stable Avalonia 11.x (or 12 if stable) and central package versions.
2. The app is a client of the agent: it talks to the background agent over the M3-1 control channel and never syncs in-process. If no agent service is installed, it offers to install and start it for the current user (the same code as `async-cli service install`); if the service is installed but not running, it starts it.
3. Screens:
   - First run / not enrolled: enter the server address, then either a code (K7QD-M2XP-9RWA style, also accepting a pasted `async://pair?...` link) or the device-code flow (shows the code and opens the approval link in the browser, polls until approved). Device name defaulting to the machine name.
   - Main: this device and server, connection state, folders assigned to it with mode/encryption, local path, state (idle/syncing/backing up with live progress from the event stream), last result and next run, overdue/failing from the server, pause/resume, sync now, "open folder" in the file manager, "choose local folder" (native folder picker) for folders without a path or to change it.
   - Unlock end-to-end folders: passphrase or recovery key, never echoed or logged.
   - Settings: start at login, theme (light/dark/system), open the web UI, about/version, sign out of this device (forget identity, with confirmation).
   - Tray: status icon (ok / syncing / problem), menu with sync now, pause all, open window, open web UI, quit. Closing the window keeps the tray app running; Quit stops the tray app, not the agent service.
   - Desktop notifications for sync failures and conflicts (respect a setting).
