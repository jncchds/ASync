Asked by the person: "I want to be able to add folders from the Android app too somehow." Design approved by the person:
- Device endpoints (Roles.Device) for: creating a new folder owned by the device's owner, on that owner's own storage back-ends or shared back-ends they may use (exactly the rules of the people's endpoint), with this device attached; and attaching this device to an existing folder of the owner (and detaching itself). Never other devices, never account management, never storage back-end management or secrets.
- A per-device flag "May add folders" that the person controls in the web UI (Devices page). Default on for devices enrolled with a one-time code or the device-code flow (phones, desktops); off for devices enrolled with a reusable code (scripted CLI agents). A migration for the flag (through `dotnet ef`). The endpoints answer 403 with a clear message when it is off.
- The web UI and other devices see the change live (config.changed / folder.changed), and the owner can edit or remove the folder from the web as usual.
